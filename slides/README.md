# Slides

Drop images here (PNG or JPG, 16:9 such as 1920x1080 looks best). Each one rotates in the spotlight for 25 seconds.

- Optional dates: start the file name with them, `2026-11-16_2026-11-18_turkey-bowl.png`, to show it only on those days.
- Order: slides play in alphabetical order of file name.
- To remove a slide, delete the file.

The slide list updates automatically within a minute or two of each upload.
